# Field

A labelled text input: label above in stone, a sheet box with a stone border, an ochre "Error:" band below when invalid.

`radius-sm`, height `target`, 1px `stone` border (not `line`: an input's edge must show at 3:1). Measurements in the `data` family. Focus: 2px `ink` ring, 2px offset. Invalid: an `attention` band under the field starting with "Error:", linked by `aria-describedby`. The label carries the unit: "Thickness (mm)".
