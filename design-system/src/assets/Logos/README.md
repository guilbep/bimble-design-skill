# Logos

- `bimble-mark.svg`: the main mark (study 6), clay and pink discs, ink letters. App, installers, web page.
- `bimble-mark-on-cream.svg`: the same on the cream ground.
- `bimble-mark-lab.svg`, `-on-cream`: the lab mark (study 7, moss). Builds under test only, so they never look like a release.
- `bimble-icon.svg`, `bimble-icon-lab.svg`: the single "b" disc for app bars and favicons.
- `study-3-slate-pink.svg`, `study-4-slate-ochre.svg`: earlier studies, kept for reference. Don't ship them.

The letters are always ink `#141414`. Never recolour, outline, rotate or add effects.
